# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take the security and privacy of **SubTranscribe Studio** seriously. Because SubTranscribe Studio operates entirely locally on user machines without transmitting data to external servers, privacy risks are minimized by design.

However, if you discover a security vulnerability or concern:

1. **Do NOT open a public issue.**
2. Email your report directly to **`hossainakash22958@gmail.com`**.
3. Please include:
   - Description of the vulnerability.
   - Steps to reproduce or proof-of-concept.
   - Any potential impact.

We will acknowledge receipt within **48 hours** and provide periodic updates as we address the issue. Thank you for helping keep SubTranscribe Studio safe and secure!
